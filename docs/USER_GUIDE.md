# 西渡 · 客户使用手册

> 面向：用西渡把中文网文编译成外语的**客户**（作者、版权方、发行方），
> 不是开发者。开发者看 [`../README.md`](../README.md)。

## 1. 西渡做什么

西渡**不是逐字翻译**，而是"文化编译"。中文网文里大量文化包袱（鬼节、风水、
称谓、成语、谐音梗）对中文读者是"秒懂"，对外国读者却是一片空白。西渡的管线
会先识别这些"外国读者看不懂的地方"，再把画面用外国读者能感知的方式重建出来，
目标是让译文"读起来不像翻译"。

## 2. 快速上手

1. 打开首页（部署方会给你地址）。
2. 上传小说文件（`.txt` / `.md`，单文件 ≤ 50MB）。
3. 选目标语言（`en-US` / `es-ES` / `de` / `fr`）和术语预设。
4. 提交，等待编译完成。

> 编译是异步的：提交后可以关掉页面，进度随时在「运行看板」查。

## 3. 编译过程（后台发生的事）

五节点管线，每章走一遍：

| 节点 | 做什么 |
|---|---|
| READ | 读中文原文，识别文化缺口、画面缺口，提出术语译法 |
| REVIEW_TERMS | 核对本章术语与已建立术语库的一致性 |
| WRITE | 用目标语重写本章（不是翻译，是讲故事） |
| READBACK | **冷读盲评**：只看英文、不看原文，判断"读得懂吗、想追更吗" |
| FIX | 只修冷读者指出的具体问题，修完再冷读（最多 2 轮） |

大部分章节走**快速模式**（跳过冷读）；每 20 章抽一章走**完整模式**（含冷读）。

## 4. 人工参与（可选，但建议）

- **术语审校** `/review`：机器提出"这个名该译成什么"，你点确认/拒绝。确认过的译法会锁进术语库，全书统一，不会翻到后面又变了。
- **逐段润色** `/editor/{job_id}`：对任意章节一段段人工改稿，改动会被记录。

## 5. 导出

- **EPUB**：`GET /api/epub/{job_id}`（或由部署方在界面提供下载入口）。
- **译稿**：`.md` 文件落在 `output/` 目录，每章一份。

## 6. 质量说明

- 冷读 `PASS` 代表"英语读者读得懂、想追更"；`NEEDS_FIX` 会自动进入修补循环。
- 术语库分两层：SQLite 精确匹配 + Chroma 语义召回，保证全书译名统一。
- 已验证：两本全书（775 章、2301 章）冷读全 PASS、0 崩溃。

## 7. 支持的语言

| 代码 | 语言 | 状态 |
|---|---|---|
| `en-US` | 英语 | ✅ 已验证（母语读者 + 双语审计 + 专业编辑三轮） |
| `es-ES` | 西班牙语 | 🟡 术语数据有，质量未做母语者验证 |
| `de` | 德语 | 🟡 同上 |
| `fr` | 法语 | 🟡 同上 |

> 若你需要非英语语种，请与部署方确认该语种是否已做母语者质量验证。

## 8. 常见问题

| 问题 | 说明 |
|---|---|
| 上传失败 | 检查文件格式（txt/md）和大小（≤50MB） |
| 进度卡住 | 到「运行看板」看是否有报错；联系部署方看 worker 日志 |
| 某个译名想改 | 到 `/review` 拒绝旧译法、确认新译法 |
| 想换目标语言 | 新开一个编译任务，选新语言 |
